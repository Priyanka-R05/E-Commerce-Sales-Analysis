# E-Commerce Sales Analysis & Prediction

## 📌 Project Overview

This project analyzes e-commerce sales data to understand sales performance and identify useful business insights. It also uses a Machine Learning model based on Linear Regression for sales prediction.

## 🎯 Objectives

- Analyze e-commerce sales data
- Calculate total and average sales
- Identify highest and lowest selling products
- Analyze sales trends
- Visualize sales data using charts
- Predict sales using Machine Learning

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Tkinter
- VS Code

## 📊 Key Features

- E-commerce sales data analysis
- Product-wise sales analysis
- Monthly sales trend visualization
- Total and average sales calculation
- Highest and lowest sales identification
- Sales prediction using Linear Regression
- Simple GUI application using Tkinter

## 🤖 Machine Learning

A **Linear Regression** model is used for sales prediction based on the available sales data.
